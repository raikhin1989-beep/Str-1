# Правила подсчёта очков

Формулы реализуются в `app/scoring.py` чистыми функциями и покрываются тестами.
Менять правила — только здесь и там, одновременно.

## Формат конкурса

Админ заранее задаёт список виски дегустации (обычно 5–8). Образцы разливаются
под номерами `1..N`, соответствие «номер ↔ виски» знает только админ.

**Из чего выбирают ответ** — настройка дегустации (`answer_scope`):

* **из всего справочника** (по умолчанию) — в списке все виски, какие заведены,
  а не только налитые. Назвать можно то, чего на столе нет: не узнал розлив —
  назови похожий, за верный класс дадут балл. Чем больше справочник, тем
  сложнее конкурс;
* **только из налитого** — режим полегче: конкурс превращается в перестановку
  известных названий по номерам.

Одно название нельзя поставить двум образцам в обоих режимах.

Почему по умолчанию справочник: с закрытым списком из N названий промахнуться
«в свой класс» можно было только переставив два образца местами, и частичный
балл почти не срабатывал — то есть правило было, а работать ему было негде.

Два раунда:

1. **По запаху** — участник расставляет все образцы, ориентируясь только на нос;
2. **По вкусу** — расставляет заново, уже попробовав.

Во втором раунде свои ответы из первого участник не видит: иначе бонус за
постоянство теряет смысл.

## Начисление

| За что | Баллы |
| --- | --- |
| Верное попадание в раунде **по запаху** | **3** |
| Верное попадание в раунде **по вкусу** | **2** |
| Промах, но названный виски той же категории, что верный | **1** (в любом раунде) |
| Образец угадан **и** по запаху, **и** по вкусу | **+1** бонус за постоянство |
| Весь раунд без единой ошибки | **+3** бонус за чистый раунд |

Почему нос дороже вкуса: вслепую попасть по запаху заметно труднее, и именно там
видно мастерство. Кто взял нос, вкус чаще всего доберёт — за это отдельная,
меньшая награда.

Почему есть частичный балл: без него вечер превращается в «всё или ничего»,
и человек, который безошибочно слышит торф, но путает винокурни, уходит с нулём.
Категорию каждому виски проставляет админ (см. ниже).

Балл за категорию и балл за точное попадание не складываются: за образец
начисляется либо полный балл раунда, либо частичный, либо ноль.

## Тай-брейк

При равенстве суммы:

1. больше очков за раунд по запаху;
2. кто раньше отправил ответы второго раунда.

## Категории для частичных баллов

Гранулярность выбирает админ при заведении дегустации:

* **класс** — односолодовый скотч / купажированный скотч / односолодовый (не Шотландия) / бурбон / теннесси / ржаной / прочее;
* **регион** — Islay / Speyside / Highland / Tennessee и т.д.

Для первой дегустации (см. `docs/TASTING-001.md`) выбран **класс**: в её составе
только два односолодовых, и они из разных регионов — на уровне регионов частичные
баллы не достались бы никому.

## Максимум

`N × 3` (нос) `+ N × 2` (вкус) `+ N × 1` (постоянство) `+ 3 + 3` (чистые раунды).

| Образцов | Максимум |
| --- | --- |
| 5 | 36 |
| 6 | 42 |
| 8 | 54 |

## Пример на пяти образцах

Участник угадал по запаху 2 образца, по вкусу 4 (те же 2 плюс ещё 2),
один промах пришёлся на виски того же класса:

```
нос:          2 × 3 = 6
вкус:         4 × 2 = 8
постоянство:  2 × 1 = 2
категория:    1 × 1 = 1
чистых раундов нет
────────────────────
итого                17  из 36
```

## Что считается отдельно от конкурса

Каждый участник ставит каждому образцу личную оценку 0–100 и отмечает теги
(торф, дым, ваниль, яблоко, специи, сухофрукты, орех, солод, ваниль, карамель…).

В зачёт это не идёт. Нужно для двух вещей: «виски вечера по мнению стола»
(среднее по оценкам) и личной итоговой карточки с профилем вкуса.

## Крайние случаи, которые обязаны быть в тестах

* участник не сдал раунд вовсе — ноль за раунд, в таблице не исчезает;
* участник расставил не все образцы — считаются только заполненные;
* участник зарегистрировался, но не участвовал — в таблице с нулём, помечен;
* полное совпадение сумм у двух и более участников — работает тай-брейк;
* дегустация из одного образца — бонус за чистый раунд не превращается в халяву
  (при `N < 3` бонус за чистый раунд не начисляется).
