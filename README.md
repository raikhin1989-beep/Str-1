# Str-1

Статический сайт, который деплоится на тот же сервер, где живёт проект
[Str](https://github.com/raikhin1989-beep/Str).

Сейчас в `site/` лежит заглушка — назначение сайта ещё не определено.

## Как устроено

- `site/` — содержимое сайта, отдаётся как есть, без сборки;
- `.github/workflows/deploy.yml` — деплой по SSH; пуш в `main` выкладывает сайт
  на сервер.

Чтобы не конфликтовать с уже работающим сайтом Str, этот проект использует
собственный каталог `/var/www/str-1` и свой экземпляр Caddy на порту 8081.
Домен и HTTPS обслуживает основной Caddy — порты 80 и 443 может занимать
только один процесс. Подробности — в `CLAUDE.md`.

## Домен

Поддомен на duckdns.org **заводится руками** через их веб-интерфейс: API
создания у DuckDNS нет, только обновление IP уже существующего имени. После
регистрации нужны секреты `DUCKDNS_SUBDOMAIN` (метка без `.duckdns.org`) и
`DUCKDNS_TOKEN` — дальше деплой сам обновит A-запись и получит сертификат.
Пока секретов нет, сайт живёт только на порту 8081.

## Проверить, что выложено

```sh
curl http://<адрес сервера>:8081/version    # SHA задеплоенного коммита
curl http://<адрес сервера>:8081/healthz    # -> ok
curl https://<домен>/version                # тот же SHA
```
